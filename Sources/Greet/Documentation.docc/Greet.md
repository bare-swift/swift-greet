# ``Greet``

A friendly greeter — the throwaway demo package that proves the bare-swift Phase 0 pipeline works end-to-end.

## Overview

`Greet` exposes a single static function, ``Greet/greet(name:)``, which returns a polite greeting for the given name. Whitespace is trimmed; empty input falls back to "friend".

This package exists to validate that the bare-swift scaffold, CI, DocC, and release pipeline all function. It is not intended for production use.
